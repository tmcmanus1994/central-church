# Weekly bulletin run summaries

One `{date}-summary.md` per week the automation actually changed something —
see `.claude/skills/weekly-bulletin/SKILL.md` and `automation/README.md`.
Each summary is committed with the content change it describes, so the
commit shows what changed and why.

These are safe to read: the skill never writes named health details,
showers, phone numbers, personal emails, or giving figures into a summary —
see rule 4 in the skill. The raw email and PDF those summaries are drawn
from live in Travelle's Drive folder "Central Bulletins" and are never
committed.

Summaries before 2026-10-18 were written by the retired GitHub Actions
workflow and refer to its PR-based flow.
